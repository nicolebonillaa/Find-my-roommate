# RoomieReport

A roommate review platform for CSUN students. Learn what it is like to live with someone before choosing them as a roommate.

## Features

- **CSUN student profiles:** bio and lifestyle preferences
- **Roommate connection requests:** send, accept, or decline
- **Verified roommate reviews:** only from people who actually lived together
- **Double-blind review reveal:** neither person sees the other's review until both submit or the deadline passes
## Tech

- React + Vite
- Firebase Authentication
- Cloud Firestore
- Cloud Functions
## Run locally

```bash
npm install
npm run dev
```

## Privacy rule

> Reviews are hidden until a roommate request is accepted. New reviews stay private until both people submit or the deadline passes.
